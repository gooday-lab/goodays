# GoOdays

Website affiliate bilingual (Indonesia / English) dengan desain minimalis berbasis warna:

- Deep Forest Green `#164A3A`
- Vibrant Orange `#FF6B35`
- Warm Cream `#F7F3EA`
- Charcoal `#202522`

## Jalankan lokal

Dari folder ini, jalankan:

```bash
python -m http.server 4173
```

Lalu buka <http://localhost:4173>.

## Publikasi gratis

### GitHub Pages

1. Buat repository baru di GitHub, misalnya `gooodays`.
2. Upload `index.html`, `styles.css`, `script.js`, dan folder `assets`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/root`.
5. Simpan. GitHub akan memberi alamat gratis seperti `https://username.github.io/gooodays/`.

### Netlify / Vercel

Buat akun gratis, pilih **Add new project / site**, lalu upload folder `gooodays-site` atau hubungkan repository GitHub. Keduanya akan memberikan subdomain gratis.
